## 3. A tethered frame carries the double cover (orientation-entanglement)

Now act with the emergent spatial rotation group. ED's 3D space is emergent; a node carries a local **frame** (its orientation / P09-polarity assignment distributed across its channel-directions), and spatial rotation SO(3) rotates that frame, hence rotates the channel-directions.

The topological fact about SO(3): **π₁(SO(3)) = ℤ₂.** A 2π rotation is a *non-contractible* loop in the rotation group; a 4π rotation is contractible. For a *free* point this is invisible. For a **tethered** object it is physical — this is the Dirac belt / scissors / orientation-entanglement relation:

> Rotate a tethered frame by 2π: its tethers are left **twisted**, and no motion of the frame alone removes the twist. Rotate by 4π (or 2π then run the belt trick through the tethers): the twist is removable. The twist class is exactly the ℤ₂ of π₁(SO(3)).

An ED node *is* tethered (by its channels), so its configuration space under rotation has this ℤ₂. An object whose state must keep track of that twist transforms under the **universal (double) cover SU(2)**, picking up the −1 under 2π. **That is spin-½.** The half-integer spin is not put in; it is forced the moment a frame is *tethered to the graph* and rotated.
