# Intrinsic-memory probe — results

**Date:** 2026-07-06
**Status:** RUN, confirmed over long runs. The strongest positive result of the night's whole Higgs/mass line — genuine, stable, bounded slowing, caused entirely by a chain's own carried history, no external reference position anywhere. Still requires new state (honestly named) and free coupling parameters — read the scope section before treating this as more than it is.

## The question

The fourth-pass structural finding (`V5_Envelope_Shape_From_P11_Scoping.md`) established the certified substrate has no channel for a chain's own history to be both carried forward *and* actually read by its movement rule — the two candidate channels (orientation, density) each have only one of those two properties, never both. The direct fix, and the most honest next test: build a third channel that genuinely has both, and see whether real (not faked) memory produces mass-like behavior on its own.

## What was built

A new, chain-carried scalar (`chain_mem`), tracked outside the certified `NodeState` object (so the certified code itself is untouched — this is an addition, not a modification). At every commit — dwell or advance, treated identically — the value updates by `new_mem = decay·old_mem + 1`, and is carried forward to whichever node the chain commits to next, exactly the way `orientation`'s transverse component already is. The one new piece of coupling: the self-loop candidate's Sigma value gets a bonus proportional to the chain's *own* current `chain_mem` — no fixed source position anywhere in the code, no reference to any other chain's history. Everything else (`compute_candidates`, `compute_sigma`, `apply_tiebreak`, `commit()`) reused verbatim from the certified module.

## Result

**With no fade (`decay=1.0`):** memory grows without bound, and velocity keeps falling continuously across the whole run (0.56 → 0.31 → 0.25 → 0.21 → 0.20 → 0.17 → 0.16 → 0.15, no sign of leveling off) — runaway, not mass. Ruled out as the right regime, exactly as predicted before running: real mass doesn't keep growing.

**With fading memory (`decay<1`):** the result changes qualitatively, not just quantitatively. Memory converges to a fixed steady-state value (as it must, algebraically, for any `decay<1`), and — this is the finding — **velocity converges too**, dropping from near-ballistic (~0.9) down to a stable plateau and then *staying there*. Confirmed over a much longer run (8000 steps, 6 seeds, `decay=0.95`): velocity drops through an initial transient (windows of 200 steps: ~0.8-0.9 → ~0.6-0.7) and then holds essentially flat for the rest of the run (last 1000 steps averaged: v_eff = 0.720 ± 0.020 across seeds). Every run reached the far boundary — full survival throughout, no stalling, no dying.

**The coupling strength and the fade rate trade off as expected, and sensibly.** A weaker coupling (`k_mem=0.05`) needs a slower fade (`decay=0.95`, steady-state memory ≈20) to produce a visible effect; the same coupling with a faster fade (`decay=0.8`, steady-state memory ≈5) shows no effect at all — but a stronger coupling (`k_mem=0.2`) at that same fast fade reproduces the same kind of plateau. What matters is the product of coupling strength and steady-state memory level, not either alone — internally consistent, not an accident.

## Why this is the strongest result of the night

Every earlier positive result in this line needed something external: the field-decay probe needed a fixed reference position (not itself justified); the dwell-channel's original `kg>ks` needed an unexplained coefficient asymmetry. This result needs neither. It's the first mechanism where the "heaviness" is a property the chain **carries with it**, not something tied to a place in space or an arbitrarily-tilted default — which is a much closer match to what mass actually is (an intrinsic property of a particle, not a location-dependent one).

## Honest scope — what this is and isn't

**This required adding new state to the certified reference substrate — named honestly, not smuggled in.** `chain_mem` is not something P02–P13 already provide "for free" — it's a genuinely new channel, of exactly the kind the fourth-pass finding said would be needed to close this gap. Whether *this specific* channel (a simple exponential-decay accumulator) is the *right* one, or whether it can be derived from existing primitives rather than added as new structure, is untested.

**Two free parameters, same pattern as everywhere else tonight.** The coupling strength (`k_mem`) and fade rate (`decay`) were both chosen to get a working demonstration — neither is derived. This is the same "form works, specific value not yet grounded" pattern found repeatedly tonight (`kg>ks`, the field-decay length), not a new kind of gap.

**This is still one lone particle, not a Higgs mechanism.** No gauge coupling, no symmetry breaking, no condensate — this shows a single chain can carry genuine, bounded, intrinsic sluggishness. Whether *this* mechanism (rather than the earlier field-decay one) can be extended toward an actual gauge-boson-mass story is a fresh, unexplored question — the four missing pieces named in `Dwell_To_GaugeBoson_Coupling_Scoping.md` (no gauge-boson object in the sim, H1's unfinished vertex, the field-vs-condensate mismatch, no standing background ever built) still all apply here as much as they did before; this result doesn't touch any of them directly, it solves a different, narrower problem (does *any* real, chain-carried mechanism give bounded intrinsic mass at all — yes).

## Attempt to reduce the two free parameters (same session, 2026-07-06)

Tried to eliminate the coupling strength `k_mem` by folding memory into the *existing* coherence weight `kc` instead of giving it its own new weight — shift the self-loop's coherence *target* by the chain's accumulated memory (`target = rho_star + chain_mem`, with `chain_mem` growing by `coeffs.increment`, the same quantity `rho` already grows by) rather than adding a separately-weighted bonus term. P12's own canonical definition is a fixed three-term functional; a fourth, independently-weighted term is more new structure than strictly necessary if it can be avoided.

**Result: failed, honestly.** At every ordinary fade rate tested (`decay = 0.9, 0.95, 0.98`), this version showed *no* slowing effect at all — velocity stayed at the pure-ballistic baseline (~0.97) regardless of decay rate, a flat, uninformative result across values that should have differed if the mechanism were doing anything. Only the extreme, unphysical `decay=1.0` case showed any effect, and it was messy and inconsistent across seeds (most runs failed to even reach the chain's far boundary within budget), not the clean plateau found before.

**Why it fails, understood, not just observed:** shifting the *target* a chain compares against is not mechanically equivalent to directly rewarding staying. When accumulated memory pushes the target far from where local density actually sits, it makes the self-loop's coherence term *worse* (density is now far from the shifted target), not better — the opposite of what's needed to make dwelling attractive. The original design's directly-additive bonus avoided this because it rewards staying unconditionally, regardless of density. **`k_mem` is not redundant with `kc` — it does genuinely separate work, and this specific economy attempt doesn't get to keep it.**

**The fade rate, by contrast, is not actually a new unknown — it should be named plainly as what it already is.** V1's own canonical definition (`Paper_089_V1Kernel.md`) is explicitly "chain C's response... to substrate-level perturbations at the same chain's earlier locus" — exactly what `chain_mem` implements. The fade rate here isn't a fresh, unexplained number invented for this probe; it's the corpus's own already-acknowledged, already-inherited V1 memory time τ_V1, now identified with a concrete, working piece of code for the first time (Paper_090 confirms no paper anywhere has implemented V1/V5 in running code before tonight). This doesn't derive τ_V1's *value* — Paper_089 itself says that value stays inherited, same as every other regime-specific τ_V5 identification in the corpus — but it means there is exactly **one** genuinely new free parameter here (`k_mem`), not two.

## Fifth pass (same session, 2026-07-06) — the two parameters are not independent; only their product matters

Prompted by AP recalling that his book describes ED-QM's ℏ informally as "memory" — checked directly against the canonical technical paper first (`Paper_012_RB1_RateOfBecoming.md`): ℏ there is a phase-rate normalization (E/ℏ), not framed as a memory window in the formal papers. Treated the book's framing as a hypothesis to test, not a given, and tested it against a concrete, already-established corpus fact instead: "each substrate event carries action ℏ" (from tonight's Θ_ED grounding work). If each commit carries one unit of this, the natural, minimal memory window would be *order 1* — remembering roughly one commit's worth, not the ~20-commit window the original working case used.

**First test, misleading on its own:** holding the coupling strength (`k_mem`) fixed and sweeping the fade rate down toward an order-1 window showed a sharp, clean transition — essentially zero effect for a steady-state memory of 10 or less, a real effect only appearing around 20. Taken alone, this looks like a rejection of the order-1/ℏ-scale hypothesis.

**Second test caught the real structure.** Holding the *product* of coupling strength and steady-state memory constant instead (at the value that worked before, ≈1.0) and sweeping window size from a genuine few-step memory (`decay=0.5`, steady-state ≈2, confirmed by inspecting the actual memory trace: 0 → 1.0 → 1.5 → 1.75 → ... converging smoothly to 2.0 over about six steps, real accumulation, not a degenerate instant reset) up to the original 20-step window — **the plateau velocity comes out essentially the same across the whole range** (0.657 to 0.720, all within noise of each other). The earlier "sharp transition" was an artifact of holding the wrong thing fixed: **window size on its own is not what determines whether the effect appears — only the product of window size and coupling strength is.**

**This is real, useful simplification, not just a relabeling.** It means the original framing ("two free parameters, need to reduce them") slightly overcounted the actual degrees of freedom — for the purpose of producing the plateau, there is effectively **one** combined free quantity, not two independent ones. And it means the book's "ℏ = memory" framing is not ruled out: a short, genuinely multi-step (few-commit) memory window works exactly as well as the original long one, provided the coupling strength scales up to compensate — and at that short-window end, the required coupling (`k_mem ≈ 0.5`) sits at the same order-1 scale as the substrate's other existing weights (`kc=ks=kg=1`), rather than the original probe's small, oddly-specific `0.05`.

## Sixth pass (same session, 2026-07-06) — checking the G-formula connection AP raised

AP connected the "ℏ = memory" framing to an already-closed ED result: `G = c³ℓ_P²/ℏ` (`Paper_027_Newtons_G.md`), read as (speed of influence) × (grain)² / (memory) — and that reading matches how the paper itself describes the pieces (c = "substrate-level speed," ℓ_P = "substrate scale," ℏ = "substrate-level kernel-action quantum"). This is real, valid precedent — ℏ-as-memory isn't isolated to the book's informal framing; it's consistent with how ED's own closed formula already treats the quantity.

**Checked whether this could supply the still-missing free parameter (the coupling-strength × window-size product found in the fifth pass) — verified with an explicit dimensional-analysis calculation, not just by inspection: it cannot, and this is provable, not just unclear.** c, ℓ_P, and ℏ alone admit only the *trivial* dimensionless combination (all exponents zero) — a genuine pure number cannot be built from these three constants without a fourth, independent ingredient (a mass, a rate, or an energy scale). This matters because the fifth pass's product is exactly such a dimensionless number in the toy-lattice model.

**This doesn't close the question, but it precisely locates what's still missing, and points back at an already-open thread.** The natural fourth ingredient — a rate — is exactly what the earlier P11-envelope-shape work (`V5_Envelope_Shape_From_P11_Scoping.md`) was independently trying to identify (the commitment rate Γ). Two separate lines of reasoning tonight — the memory-window product here, and the envelope-decay-length work there — both bottom out on needing the same kind of missing ingredient: an intrinsic substrate rate, not yet derived. Not a coincidence worth ignoring.

## Seventh pass (same session, 2026-07-06) — is the commitment rate the missing fourth ingredient?

Followed the sixth pass's pointer: the missing dimensionless quantity needs a fourth ingredient (a rate), and P11's commitment rate `Γ_commit` was the natural candidate. Corpus recon result (full report in session history) and a dimensional check:

**The good news — `Γ_commit` is real and recurring, not invented.** A commitment-rate quantity shows up independently in at least four separate ED sub-programs: quantum-computing decoherence (the strongest instance — `Arc_QC`'s `Λ_S`, a genuine Poisson-process rate that reproduces real empirical decoherence rates like superconducting-qubit T1), GR PPN screening (`κ = k₁₁·c/ℓ_P`), black-hole horizon collapse dynamics, and QFT vertex rates. Four independent arcs converging on the same structural quantity is genuine signal. Its primitive-level definition is `Γ_commit ~ b_int/(commitment-reserve budget)` (`primitives/concepts/commitment.md`).

**The catch — it never clears the bar `c, ℓ_P, ℏ` clear.** Every single instance is self-flagged by its own paper as form-FORCED (its existence/shape follows from P11), value-INHERITED (the actual number is empirical or an explicit order-of-magnitude estimate, never derived). No paper ever pins it to a clean constant, and `Paper_027` never raised a fourth constant at all.

**The sharp finding — the commitment rate is NOT a dimensionally independent fourth ingredient (verified, not asserted).** The corpus's own reading of its near-matter scale is `κ = k₁₁·c/ℓ_P` — i.e. `Γ_commit ~ c/ℓ_P` times a dimensionless factor `k₁₁`. But `c/ℓ_P` is just the inverse Planck time, already built from two of the three substrate constants. A dimensional-analysis check confirms: adding `Γ = c/ℓ_P` to `{c, ℓ_P, ℏ}` produces **no genuinely new pure number** — the only new dimensionless degree of freedom is `k₁₁` itself, the dimensionless commitment factor hidden *inside* `Γ_commit`. So the "fourth ingredient" doesn't escape the hole from the sixth pass; it relocates it precisely onto `k₁₁`, which is exactly the kind of unexplained order-1 factor the whole corpus keeps bottoming out on. This *explains why* `Γ_commit` shows up as "order-of-magnitude, form-forced, value-inherited" everywhere: its magnitude is essentially fixed at the substrate-fast scale `c/ℓ_P`, and the only free part is an O(1) number.

**What this does buy us, honestly:** it fixes the *scale* of the fade rate `λ`. If `λ ~ Γ_commit`, then in commitment units `λ` is of order the commitment rate — i.e. memory persists over a *few* commitments (a short window), not the ~20-step window originally hand-picked. That is consistent with the fifth pass (short window works fine at order-1 coupling) and with the book's short-memory intuition. What remains free is a single O(1) factor — but that factor is now identified with the same family of unexplained O(1) commitment factors (`k₁₁`) that appears across GR, QC, and QFT, rather than being a bespoke knob unique to the mass mechanism.

**A real structural connection worth flagging (candidate, not proven):** for a *freely propagating* chain in vacuum — the relevant case for a moving particle's mass — the applicable commitment rate is the *sparse* one, not the substrate-fast near-matter one. The sparseness suppression factor is exactly the same unknown the Phase-3 GR / α₁ work leaves inherited (the "sparse commitment" that the whole preferred-frame-safety argument hinges on). This raises a genuine, checkable possibility: **the mass-memory fade rate and the gravitational sparse-commitment parameter may be two faces of one underived quantity** — meaning if either were ever pinned, both would be. Not established; a connection to test, banked so it isn't lost.

## Tier verdict

**CANDIDATE, positive, confirmed over long runs, genuinely simplified.** The fold-into-`kc` reduction attempt failed cleanly (real, separate work being done). The fade-rate identification with V1's own inherited memory time stands. And the fifth pass shows the two parameters are not independent — only their product is constrained by the physics — which means an order-1, few-commit memory window (closer to the book's "ℏ = memory" framing, and to the substrate's own other natural weight scales) works exactly as well as the original, longer one. Still not FORCED — the *product's* value is not derived, only shown to be the sole thing that matters — and not yet connected to an actual gauge/EWSB mechanism. The strongest, and now best-understood, result in the night's whole Higgs/mass probe line.
